# 🪢 Raksha Bandhan Digital Gift for Srivalli (Akkoi)

> *A cinematic, deeply emotional, and interactive Raksha Bandhan memory experience created specifically by her younger brother.*

---

## 🌸 About The Project
This website is a personal interactive digital memory gift for **Srivalli (Akkoi)**. It takes her through a story of childhood memories, nostalgia, sibling chaos, sincere gratitude, an interactive Rakhi ceremony, and a brother's lifelong promise.

---

## ✨ Features & Story Chapters

1. **Cinematic Opening Screen**: Progressive emotional reveals (*"AKKOI... I made something for you..."*).
2. **Introduction**: Tribute banner for **Srivalli / Akkoi** (21) & Brother (18).
3. **Chapter 01 — Childhood & Uncle Chips Anchor Memory**:
   - The authentic 1st class memory of sharing Uncle Chips, telling endless stories, and doing nothing important.
   - Interactive memory card with clickable reveal tokens (*Food, Stories, Time together, Uncle Chips*).
4. **Persistent Photo Scrapbook (IndexedDB)**:
   - 6 Polaroid-style memory cards + 1 Final Photo slot.
   - Reusable **Photo Customizer Modal** with camera/gallery file upload and direct image URLs.
   - Automatic Canvas compression and client-side **IndexedDB storage** — photos and custom captions **persist 100% across page refreshes**.
   - Fullscreen **Lightbox** preview.
5. **Chapter 02 — The Dustbin Incident 😂**:
   - Interactive reveal of the tuition memory: *"DUSTBIN"* and her embarrassment.
   - Playful sibling banter: *"That's one of those ridiculous memories I'll never forget."*
6. **The Sibling Chaos Machine**:
   - Interactive cyclical loop: *FIGHT ➔ TEASE ➔ ANNOY ➔ LAUGH ➔ FORGET ➔ REPEAT* (*"That's basically us. 😂"*).
7. **Chapter 03 — Why You Are Special**:
   - Sincere brotherly truths presented in an intimate, darkened atmosphere.
   - Interactive connection cards (*WHEN I NEED YOU ➔ YOU'RE THERE*, *WHEN WE FIGHT ➔ YOU STILL CARE*, *WHEN I NEED SOMEONE WHO UNDERSTANDS ➔ AKKOI*).
8. **Chapter 04 — Growing Up Timeline**:
   - Visual timeline from Childhood to Today.
9. **Sacred Raksha Bandhan Transition**:
   - Festive blessing banner (*"HAPPY RAKSHA BANDHAN, AKKOI ❤️"*).
10. **Interactive Rakhi Ceremony**:
    - Animated traditional terracotta **Diya** lamp with realistic flame flickering and golden radial glow.
    - Ornate sacred gold & crimson Rakhi.
    - Tap to tie the sacred thread on brother's wrist with glowing thread animation, temple bell chimes, and confetti celebration.
11. **The Gift & Brother's Promise**:
    - Sealed wax envelope with *"OPEN YOUR GIFT"*.
    - Unfolds into a handwritten-style parchment letter with the exact verbatim promise.
12. **Final Highlight & Final Photo**:
    - Climax statement: *"NO MATTER WHAT HAPPENS... I'LL ALWAYS BE THERE FOR YOU, AKKOI. ❤️"*
    - Customizable Final Photo card (*"Until the next fight. 😂❤️"*).
13. **Audio & Soundscapes**:
    - Generative soothing Indian ambient raag synthesizer with Web Audio API (100% royalty-free, zero external audio loading failures).
    - Floating soundtrack toggle with custom MP3 URL loader.
    - Sound effects for Rakhi tying, gift unsealing, and interaction taps.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (Cinematic Obsidian & Festive Amber/Rose Palette)
- **Icons & Animation**: Lucide React + Canvas Confetti
- **Storage**: IndexedDB (`idb`) + HTML5 Canvas Image Compression Pipeline
- **Audio**: Web Audio API Ambient Synthesizer

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production (Vercel / Netlify)
npm run build
```
